# Content Creator Loop

**Status:** Planned

For blog posts, newsletters, LinkedIn content, technical articles, and other content production.

## Flow

```text
Topic → Research → Outline → Draft → Critique → Revise → Publish Checklist
```

## Roles

### Content Strategist
- Define topic, target audience, tone, and content goals.

### Researcher
- Gather reference material, data, and examples.

### Writer
- Write the first draft following the outline.

### Editor
- Critique structure, clarity, grammar, and consistency.

### Publisher
- Run publish checklist, format for target platform.

## Human Checkpoints

- Approve outline
- Approve final draft
