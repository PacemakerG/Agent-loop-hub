# Attributions

Agent Loop Hub collects, adapts, and abstracts Agent Workflow / Loop / Examples from the community.

## Policy

- If a Loop is inspired by or adapted from another project, the source must be documented in the Loop's `loop.yaml` and `README.md`.
- Direct rewrites of someone else's workflow, prompts, or document structure must include the original URL, author/project name, and license.
- Conceptual inspiration only should be marked as `Inspired by`.
- If the original project's license is unknown, mark it as `license: unknown / please verify`.

## Source Type Definitions

| Type | Meaning |
|---|---|
| `original` | Created from scratch by Agent Loop Hub contributors. |
| `inspired_by` | Conceptually inspired by another project, but not a direct copy. |
| `adapted_from` | Based on someone else's template or workflow, restructured into the Agent Loop Hub format. |
